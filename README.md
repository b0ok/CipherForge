# CipherForge

> **Cryptographic Password Suite & Zero-Knowledge Vault**  
> An end-to-end client-side password generator, information-theoretic strength auditor, and Bitwarden-grade encrypted vault.

### Highlights
- 🔐 **Zero-Knowledge Encryption**: AES-256-GCM with 600,000 PBKDF2-SHA-256 rounds.
- 🧮 **Deep Strength Scoring**: Shannon entropy, keyspace math, pattern detection, and 5 threat-model crack times.
- 🔍 **HaveIBeenPwned Intelligence**: Real-time breach verification using zero-knowledge $k$-anonymity.
- 🕒 **RFC 6238 TOTP**: Built-in 2FA authenticator with 30-second rolling codes.
- 🎲 **Multi-Mode Generation**: Random symbols, Diceware memorable passphrases, PINs, and pronounceable tokens.
- 📋 **Auto-Clearing Clipboard**: 30-second memory wiper to prevent credential snooping.
